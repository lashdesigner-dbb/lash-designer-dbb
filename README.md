# Lash Designer DBB

Site de agendamento para Lash Designer, preparado para uso em computador e celular. O projeto é uma página estática: imagens, estilos e funcionalidades estão incluídos no próprio arquivo HTML.

## Ver o site

- **No computador:** abra `index.html` no navegador.
- **Pela internet:** publique este repositório no GitHub Pages. Depois da publicação, o GitHub mostrará um endereço público para compartilhar.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html` e `README.md` para a pasta principal do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço do site aparecerá nessa mesma página de configurações.

> O site só ficará acessível publicamente depois que os arquivos forem enviados para um repositório público ou que o acesso do GitHub Pages estiver habilitado conforme as configurações da sua conta.
