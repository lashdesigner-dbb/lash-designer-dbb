# Lash Designer DBB

Site de agendamento responsivo para Lash Designer DBB, preparado para computador e celular.

## Acessar o site

[**Abrir o site de agendamento**](https://lashdesigner-dbb.github.io/lash-designer-dbb/)

## Sobre o projeto

O site permite conhecer os procedimentos, selecionar um serviço e enviar uma solicitação de agendamento pelo WhatsApp. O projeto é uma página estática: imagens, estilos e funcionalidades estão incluídos no arquivo `index.html`.

## Abrir no computador

Baixe ou clone este repositório e abra o arquivo `index.html` no navegador.
